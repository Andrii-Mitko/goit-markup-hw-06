## About the Project

WebStudio is a responsive business landing page presenting a digital agency's services, team, and portfolio.

The project focuses on mobile-first responsive design, adaptive images, interactive navigation, and modal window functionality using vanilla JavaScript.

## Features

- Semantic HTML5 structure
- Responsive and adaptive layouts
- Mobile-first CSS approach
- CSS Flexbox layouts
- Responsive images using `<picture>` and `srcset`
- SVG icons using an external SVG sprite
- Mobile navigation menu with JavaScript
- Interactive modal window
- Portfolio gallery with animated overlays
- CSS transitions and transforms
- Contact form with custom input styling and checkbox
- Newsletter subscription form UI
- Smooth scrolling

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox
- SVG
- Responsive Images
- DOM Manipulation
- Event Handling
- Google Fonts
- Modern Normalize
